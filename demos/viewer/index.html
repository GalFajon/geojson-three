geojson-three / demos

GeoJSON viewer

Drop a .geojson file anywhere in the window or open one from disk. RFC 7946 lon/lat input (no crs member) is projected to Web Mercator (EPSG:3857) through the transform option. Input with a crs member is drawn in its own units. simplestyle properties are applied. Features with a numeric height property are extruded, and invalid polygons are repaired (each repair is listed as a warning).
