geojson-three / demos

Large point sets

Synthetic utility and address points spread across a 250 × 165 km region in UTM zone 33N (EPSG:32633). Each one is its own Point feature. Points are grouped into draw batches per style and per grid cell, and each batch has its own anchor.

Features

Batch cell size (pointCellSize)

Larger cells mean fewer draw calls but bigger float32 offsets. The grid overlay shows the batch cells.

Point size

pointSizeUnits: 'world' gives points a real-world diameter, so they scale with zoom (clamped by pointMinSize / pointMaxSize). Pixel sizing keeps them constant on screen.
