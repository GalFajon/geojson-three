geojson-three

GeoJSON rendering for three.js with float64 anchoring, so data in projected or geocentric coordinates draws without float32 jitter. Each demo runs the library from source against three.js r187.

Read the guide and the API reference, or browse the source on GitHub.

Site planCadastral parcel, building with vertical walls and a pitched roof, boundary walls, road, utilities, survey points and a live GNSS rover. Covers every geometry type, in UTM zone 33N. Precision testA 20 mm survey target with a 1 mm scale bar at ECEF-magnitude coordinates. Switch between anchored and absolute-float32 vertex storage and compare measured error. Large point setsUp to 100k Point features across a 250 × 165 km region. Shows how batch cell size trades draw calls against float32 error, with picking and attribute lookup. GeoJSON editorDraw points, lines and polygons; drag vertices or whole features; insert and remove vertices; snap; delete; measure; import and export. Built on the editable Point, Line and Polygon classes. GeoJSON viewerOpen or drop your own file. Lon/lat input is reprojected, simplestyle properties are applied, attributes can be inspected and export is lossless.
Source: demos/. Run locally with npm run dev.
